# Research Strategies
- 1. within this repo: use bin/similar-prs
- 2. within this org: sourcegraph and/or gh, scoped to this github org
- 2. search for engineering articles about this a) problem b) solution space
- 3. search for open source (e.g. github) repos that solve this
- 4. search for scientific papers about this a) problem b) solution space

## Reference style
- As you research, pull the most crucial verbatim quotes from the sources, and link to source file:line or link
- Save verbatim sources to files (use a script for this (e.g. `percollate` or curl) so you don't need to read nor use tokens outputting everything).
